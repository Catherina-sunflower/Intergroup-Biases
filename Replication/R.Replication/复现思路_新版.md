# Alves et al. (2018) 数据复现思路

## 一、研究背景

本研究复现了 Alves 等人（2018）发表在 *Psychological Science* 上的研究：**共享特质与独特特质对群体偏好的影响**。

### 核心假设
当两个群体共享积极特质时，人们更倾向于选择第一个呈现的群体；当共享消极特质时，人们更倾向于选择第二个呈现的群体。

---

## 二、数据来源

- **原始数据文件**：`Alves_PsychologSci_2018_AvOr-Gleibs_92g_raw.csv`
- **样本量**：361名参与者
- **实验设计**：2×2被试间设计

### 实验条件

| 条件编号 | 条件名称 | 共享特质类型 | 第一个呈现的部落 |
|---------|---------|-------------|----------------|
| 1 | SharedPositive_A | 积极 | Purple Alien A |
| 2 | SharedNegative_A | 消极 | Purple Alien A |
| 3 | SharedPositive_B | 积极 | Brown Alien B |
| 4 | SharedNegative_B | 消极 | Brown Alien B |

---

## 三、复现步骤

### 步骤1：数据导入与预处理

#### 1.1 读取数据
```r
raw_data <- read.csv("Alves_PsychologSci_2018_AvOr-Gleibs_92g_raw.csv", 
                     stringsAsFactors = FALSE, encoding = "UTF-8")
```

#### 1.2 删除无关列
```r
cols_to_remove <- c("StartDate", "EndDate", "Status", "IPAddress",
                   "RecordedDate", "DistributionChannel", "UserLanguage",
                   "PROLIFIC_PID", "Finished","gender_3_TEXT",
                   "ethnicity_10_TEXT","comments")
data <- raw_data[, !names(raw_data) %in% cols_to_remove]
```

#### 1.3 数据清理
```r
# 删除第一行（变量说明行）
data <- data[-1, ]

# 删除部落偏好为空的行
data <- subset(data, tribe_preference != "" & !is.na(tribe_preference))

# 只保留分析所需列
dat <- data %>% select(condition, tribe_preference)
```

#### 1.4 类型转换
```r
dat$condition <- as.numeric(dat$condition)
dat$tribe_preference <- as.numeric(dat$tribe_preference)
```

---

### 步骤2：变量重编码

#### 2.1 条件分组
将4个实验条件合并为2个理论条件：

```r
# SP = 共享积极特质（条件1 + 条件3）
# SN = 共享消极特质（条件2 + 条件4）
dat$condition_rec <- ifelse(dat$condition %in% c(1, 3), "SP", "SN")
```

#### 2.2 部落偏好重编码（关键步骤）

**原始编码**：
- `0` = Purple Alien A
- `1` = Brown Alien B

**重编码目标**：将偏好转换为"选择第一个呈现的部落"或"选择第二个呈现的部落"：

```r
dat$tribe_preference_rec <- NA

# 条件1和2：Purple A先呈现
# 选A(0) = 选第一个 = 0；选B(1) = 选第二个 = 1
mask_12 <- dat$condition %in% c(1, 2)
dat$tribe_preference_rec[mask_12] <- dat$tribe_preference[mask_12]

# 条件3和4：Brown B先呈现（需要反转）
# 选B(1) = 选第一个 = 0；选A(0) = 选第二个 = 1
mask_34 <- dat$condition %in% c(3, 4)
dat$tribe_preference_rec[mask_34] <- 1 - dat$tribe_preference[mask_34]
```

**重编码逻辑表**：

| 条件 | 第一个呈现 | 选A(0) | 选B(1) | 重编码结果 |
|-----|-----------|--------|--------|-----------|
| 1 | A | 0（第一个） | 1（第二个） | 0, 1 |
| 2 | A | 0（第一个） | 1（第二个） | 0, 1 |
| 3 | B | 1（第一个） | 0（第二个） | 0, 1 |
| 4 | B | 1（第一个） | 0（第二个） | 0, 1 |

---

### 步骤3：描述性统计

各条件下的偏好分布：

| 条件 | 选第一个部落(0) | 选第二个部落(1) |
|------|----------------|----------------|
| 条件1 (SP-A) | 62 | 28 |
| 条件2 (SN-A) | 39 | 52 |
| 条件3 (SP-B) | 62 | 29 |

### 步骤4：核心分析（2×2卡方检验）

#### 4.1 构建列联表

```r
myTable <- table(dat$condition_rec, dat$tribe_preference_rec)
```

**列联表**：

|          | 选第一个部落(0) | 选第二个部落(1) |
|----------|----------------|----------------|
| **SP** | 124 | 57 |
| **SN** | 78 | 102 |

#### 4.2 卡方检验

```r
chi_result <- chisq.test(myTable, correct = FALSE)
```

**检验结果**：

| 指标 | 值 |
|------|-----|
| χ² | 23.209 |
| df | 1 |
| p值 | 1.45e-06 |
| N | 361 |

#### 4.3 效应量计算

```r
n <- sum(myTable)
chi2 <- unname(chi_result$statistic)
cohens_w <- sqrt(chi2 / n)  # = 0.25355
```

## 五、关键发现

### 百分比分析

| 条件 | 选第一个部落 | 选第二个部落 |
|------|------------|------------|
| **SP (共享积极)** | 68.5% | 31.5% |
| **SN (共享消极)** | 43.3% | 56.7% |

### 研究结论

✅ **复现成功**！结果与原始研究完全一致：

1. **共享积极特质时**：参与者显著倾向于选择第一个呈现的部落（68.5% vs 31.5%）
2. **共享消极特质时**：参与者显著倾向于选择第二个呈现的部落（56.7% vs 43.3%）
