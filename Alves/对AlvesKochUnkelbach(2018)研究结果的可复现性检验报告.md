### 1.2 文献介绍

Alves, Koch & Unkelbach（2018）提出了群体间偏见的认知-生态学解释。该理论认为，人们对陌生群体（如外群体、少数群体）的负面偏见可能源于基本认知过程与信息生态结构的交互作用。认知层面：陌生群体主要与独特特质（即与其他群体区别开来的特质）相关联；生态层面：在信息生态中，独特特质更可能是负性的。

实验 1 直接操纵了共享特质和独特特质的效价，检验对群体偏好的影响。实验 2 通过操纵积极/消极特质的多样性（diversity）间接影响独特特质的效价，并检验 phi 系数的中介作用。实验 3 通过操纵积极/消极特质的频率（frequency）间接影响独特特质的效价，重复验证中介模型。

### 2.2 原研究方法简介

**研究设计与分析方法：**

- **实验 1：** 2（条件：积极共享+消极独特 vs. 消极共享+积极独特）× 2（偏好：第1组 vs. 第2组）。主要分析：Pearson 卡方检验（无连续性校正）。
- **实验 2：** 条件 → phi 系数 → 群体偏好的中介模型。主要分析：卡方检验、t 检验、中介效应分析（lavaan 包，稳健标准误）。
- **实验 3：** 实验 2 的复制，操纵频率而非多样性。分析方法同实验 2。

**软件及软件包：** 原文献使用 R 语言（lavaan 包）进行分析。复现同样使用 R 语言（tidyverse、lavaan、vcd 包）。

### 2.3 复现思路说明

#### 2.3.1 复现范围

本复现覆盖 Alves, Koch & Unkelbach（2018）全部三个实验的核心统计分析：

- **实验 1：** 条件操纵（积极共享+消极独特 vs. 消极共享+积极独特）对群体偏好的影响，采用 Pearson 卡方检验。
- **实验 2：** 条件 → phi 系数 → 群体偏好的中介模型，包括：条件与偏好的卡方检验、phi 系数分组分析（φ+ vs. φ− 对偏好的卡方检验）、以及基于结构方程模型的中介效应分析。
- **实验 3：** 实验 2 的复制研究（操纵频率而非多样性），分析内容同实验 2。

#### 2.3.2 数据获取与初步检查

从 OSF 仓库（https://osf.io/qenhu/）下载原始数据文件，包括 `Exp1.dat`、`Exp2.dat`、`Exp3.dat` 以及 `variables.txt`。数据格式为制表符分隔的文本文件（.dat），使用 R 的 `read.table(..., sep = "\t")` 读取。

数据形式非常简洁，仅包含分析所需的核心变量，说明作者在上传数据至 OSF 前已完成数据清洗和整理。

#### 2.3.3 数据预处理

**条件标签反转修正：**

根据 `variables.txt` 中的变量说明，发现原始数据中的条件标签（condition）与原文定义相反。具体而言：

- 原始数据 `condition = 0` 对应原文定义的 condition 1（积极共享 + 消极独特：positive shared / negative unique）
- 原始数据 `condition = 1` 对应原文定义的 condition 0（消极共享 + 积极独特：negative shared / positive unique）

这一现象的可能原因是数据收集平台（如 Qualtrics）的编码约定与作者的论文写作约定不一致。为解决此问题，在复现代码中对 condition 变量进行反转修正：

```
exp_data <- exp_data %>% mutate(condition = 1 - condition)
```

修正后，各条件下的偏好分布频数与原文报告完全一致（如实验 1 条件 0 和条件 1 中偏好第 1 组的人数分别为 44 和 68），验证了该修正的正确性。

**phi 系数符号反转：**

原始数据中的 phi 系数为原始计算值，其符号与原文报告的 phi 系数相反。在 phi 分组分析中，对 phi 进行了符号反转（`phi_reversed = -phi`）以匹配原文的分组逻辑。

#### 2.3.4 统计分析方法

所有统计分析均使用与原文献相同的统计模型和软件实现：

**（1）卡方检验：**

使用 R 的 `chisq.test()` 函数，设置 `correct = FALSE`（Pearson 卡方，不做 Yates 连续性校正），与原文方法一致。phi 系数基于卡方值计算：

$$\phi = \sqrt{\frac{\chi^2}{N}}$$

符号方向根据列联表中比例差异的实际情况确定，以匹配原文的 phi 符号约定。

**（2）phi 系数分组分析：**

剔除 phi = 0 的被试后，将参与者分为 φ+ 组（phi_reversed &gt; 0）和 φ− 组（phi_reversed &lt; 0），对分组后的偏好分布进行卡方检验。

**（3）中介效应分析（实验 2 和实验 3）：**

使用 `lavaan` 包的 `sem()` 函数构建结构方程模型，设定 `se = "robust"`（稳健标准误）。模型定义如下：

```
phi ~ a * condition
preference_first ~ b * phi + c * condition
indirect := a * b
total := a * b + c
```

其中 condition 为自变量，phi 为中介变量，preference_first 为因变量（二元变量）。模型设定与原文完全一致。

#### 2.3.5 结果对比方法

采用 Kambouris 等（2024）和 Hardwicke 等（2021）的百分误差（Percentage Error, PE）量化原文献与复现结果间的差异：

$$PE = \frac{|X_R - X_O|}{|X_O|} \times 100\%$$

其中 $X_R$ 为复现值，$X_O$ 为原文献报告值。

**PE 评级标准：**

| PE 范围 | 评级 |
|:-------:|:----:|
| PE = 0% | 完全一致 |
| 0% &lt; PE &lt; 10% | 次要偏差 |
| PE ≥ 10% | 主要偏差 |

除 PE 量化比较外，还进行**推论一致性检查**：比较原文与复现的 p 值是否位于 α = 0.05 边界的同一侧（即显著性方向是否一致）。对于原文仅报告范围 p 值（如 p &lt; .001、p = .069）的情况，通过复现的精确 p 值判断推论方向是否一致。

## 4 讨论

### 4.1 计算可复现性检验结果分析

本次复现成功验证了 Alves, Koch & Unkelbach（2018）的全部三个实验的核心发现：

1. **实验 1：** χ²(1, N=210) = 12.02, p < .001, φ = −.24，条件操纵对群体偏好有显著影响，成功复现。
2. **实验 2：** χ²(1, N=223) = 8.69, p = .003, φ = −.20；phi 分组分析 χ²(1, N=210) = 13.08, p < .001；中介效应分析验证了间接效应的显著性（复现 b = −0.44, p < .001），成功复现。
3. **实验 3：** χ²(1, N=208) = 3.30, p = .069（边缘显著）；phi 分组分析 χ²(1, N=204) = 6.94, p = .008；中介效应分析验证了间接效应的显著性（复现 b = −0.23, p = .010），成功复现。

### 4.2 其他思考

**（1）课程学习方面：** 本次复现加深了对 R 语言中 lavaan 包进行中介效应分析的理解，特别是在处理二元结果变量时的建模策略和稳健标准误的设置。

**（2）科学研究方面：** 验证了认知-生态学模型对群体间偏见解释的稳健性。三个实验的结果均可成功复现，为这一理论框架提供了独立的计算可复现性证据。

**（3）小组合作方面：** 复现过程中的关键挑战包括原始数据编码方式的理解、条件标签方向的确认识别、卡方检验方法（有/无连续性校正）的选择等。通过小组讨论和交叉验证，有效解决了这些问题。

**（4）课程作业方面：** 建议未来复现项目中加强对原始数据编码方式的预先检查，以及注意不同统计软件默认参数设置的差异（如 R 的 `chisq.test` 默认使用 Yates 校正）。
